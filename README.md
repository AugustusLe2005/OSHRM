# 🏢 OSHRM - Open-Source Human Resource Management System

**OSHRM Enterprise** is a lightweight, modern, open-source Human Resource Management platform designed to streamline core HR operations, including Employee Information Management, Corporate Structure, Recruitment Pipelines, Benefits & Compensation (C&B), and Real-time Analytics.

---

## ✨ Key Features

- 📋 **Employee Profile Management (HRM):** Full CRUD functionality (Create, Read, Update, Delete), real-time search, interactive profile modal, and status tracking.
- 🏢 **Organizational Structure:** Interactive department mapping, head-of-department assignments, and unit code management.
- 🎯 **Recruitment Pipeline:** Visual job requisition cards, application progress tracking, and candidate status workflows.
- 🎁 **Compensation & Benefits (C&B):** Health insurance policy tracking, professional certification allowances, and welfare management.
- 📊 **Real-time Analytics & Reporting:** Data visualization powered by Chart.js (department distribution & qualification breakdowns).

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **UI Framework:** Bootstrap 5.3
- **Icons & Visualization:** FontAwesome 6, Chart.js
- **Architecture:** Responsive Web Application / Multi-Page System (MPA)
